# Gartenjahr

Private Web-App (Google Apps Script) für die jahreszeitliche Gartenarbeit.

- Pflanzen nach Flächen (draußen und drinnen), Topf/ausgepflanzt, automatische Bewässerung
- KI-Steckbrief je Pflanze mit Schnitt-, Dünge- und Pflegeplan, Giftigkeit und Standort-Check (Claude API)
- Pflanzenbestimmung, Zustands-Check und Wachstumstagebuch per Foto
- Aufgabenspeicher mit Rasen-Jahresplan, Mähroboter- und Bewässerungsterminen
- Frost- und Trockenheitswarnungen (Open-Meteo), Gießrhythmus für Zimmerpflanzen
- Gartenplan auf Satelliten-Screenshot, Einkaufsliste, Jahresrückblick, Erinnerungs-Mails

Daten liegen ausschließlich im eigenen Google Drive (Tabelle + Ordner „Gartenjahr“). Im Code sind keine persönlichen Daten oder Schlüssel enthalten.
